## 关键判断

1. 单词没有重复，大小写和空格也没有造成重复。
2. 同一个单词的多个词性存在于“词典释义”单元格的不同换行里，不需要拆分单词行。
3. 词频字段不是排名，而是真题中出现次数。Excel 的前 1600 行大体按词频降序，
   但后续存在 5 处插入块造成局部逆序，因此转换时按 `frequency` 降序并保留原始
   `id` 作为稳定标识。
4. 例句来自真题原文摘录，同一句会同时服务于多个单词，最大复用 11 次；这不是
   数据错误，JSON 为每个单词保留其对应例句。
5. 单元格空白统一规范化为 `null`，没有删除原始 Excel 文件，也没有把无意义模板
   写入前端 JSON。
